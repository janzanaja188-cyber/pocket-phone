# Pocket Phone

มือถือจำลองเต็มจอสำหรับ SillyTavern — แชท โทร ฟีดโซเชียล กระเป๋าเงิน และอื่น ๆ กับตัวละครในเครื่องของคุณ ทำงานฝั่งเบราว์เซอร์ล้วน ไม่ต้องติดตั้งเซิร์ฟเวอร์เสริม

**เวอร์ชัน 1.4.5**

> **หมายเหตุเรื่องโควตา:** ทุกครั้งที่กดให้ตัวละครตอบ/โพสต์/คอมเมนต์/คุยสาย จะเรียกโมเดลเหมือนการโรลปกติ **จึงหักโควตา API ตามการใช้งานจริง**
>
> ส่วนการเชื่อมกับบทหลักทำงานแบบ **หนึ่งคำขอเท่านั้น** — ไม่ยิง API รอบสองลับหลัง และมีตัวนับโทเคนในตัวให้ดูว่าเปิดอะไรกินเท่าไหร่

---

## ติดตั้ง

1. เปิด SillyTavern → **Extensions** → **Install Extension**
2. วางลิงก์ repo นี้แล้วติดตั้ง
3. รีเฟรชหน้า
4. เปิดใช้งานได้จาก **ปุ่มลอย** (ลากย้ายได้) หรือเมนู **wand (Extensions)**

> อัปเดตแล้วแนะนำให้ล้างแคชเบราว์เซอร์ (ดูหัวข้อ [ล้างแคช](#ล้างแคช))

## เริ่มใช้งานครั้งแรก

หลังติดตั้ง แนะนำทำสามอย่างนี้ก่อน

**หนึ่ง** เปิดมือถือ → ตั้งค่า → เลื่อนบนสุด กดปุ่ม **"วัดเลย"** ในการ์ดโทเคน เพื่อให้ระบบวัดว่าการเชื่อมกับบทหลักกินโทเคนเท่าไหร่ในเครื่องคุณ ตัวเลขนี้มาจากตัวนับของ SillyTavern เอง ไม่ใช่การประมาณ

**สอง** ในการ์ดเดียวกัน กดปุ่ม **"เท่าที่จำเป็น"** เป็นค่าเริ่มต้นที่สมดุลระหว่างความสมจริงกับโทเคน (เปิดแชท กลุ่ม/โทร กระเป๋าเงิน รายชื่อคอนแทกต์ บันทึกกิจกรรม)

**สาม** หน้าข้อความ → ปุ่มดินสอมุมขวาบน → เพิ่มตัวละครจาก SillyTavern เข้ามาเป็นรายชื่อคนคุย

## ภาพรวมความสามารถ

Pocket Phone จำลองมือถือหนึ่งเครื่อง มีหลายแอปในตัว ทุกแอปเชื่อมข้อมูลกันและเชื่อมกับเนื้อเรื่องหลักได้ (เปิด/ปิดได้รายอัน)

### แอปข้อความ

- เพิ่มตัวละครจาก SillyTavern เข้ามาเป็นรายชื่อคนคุย
- แชทเป็นข้อความจริง กด Enter ส่ง แล้วกดปุ่มเจนให้ตัวละครตอบ พิมพ์รัวหลายข้อความก่อนค่อยให้ตอบก็ได้
- ฟองแชทจับกลุ่ม มีเส้นคั่นเวลา สถานะ "ส่งแล้ว/อ่านแล้ว" และเวลากำกับ
- แท็บรายชื่อ: ยังไม่อ่าน / ปักหมุด / ตัวละคร / NPC เรียงตามที่คุยล่าสุด
- ปัดแถวแชทเพื่อ ปักหมุด · ปิดเสียง · เก็บเข้าคลัง · ลบ
- ปัดฟองข้อความไปขวาเพื่อตอบข้อความนั้น แตะฟองเพื่อ ตอบ · ติดดาว · แก้ไข · **ยกเลิกข้อความ** · แชร์ · เลือกหลายข้อความ · ลบ
- ค้นหาในห้อง และค้นหาข้ามทุกแชทได้
- แนบได้หลายแบบ: รูป · ตำแหน่ง · การ์ดคอนแทกต์ · ข้อความเสียง · โพล (ในกลุ่ม) · โอนเงิน · ของขวัญ · ตั้งเวลาส่ง
- ปรับแต่งแยกต่อคน: พื้นหลังแชท สีฟอง สีตัวอักษร ฟองกระจก ทรงฟอง รูปเป็นพื้นฟอง เสียงเรียกเข้าเฉพาะห้อง
- Persona: ตั้งชื่อ/บุคลิกของตัวละครเฉพาะในมือถือ และเลือก persona ของผู้ใช้ที่บอทคนนั้นรับรู้ (ไม่กระทบข้อมูลจริงใน SillyTavern)

### ยกเลิกข้อความ (ต่างจากลบ)

**ยกเลิกข้อความ** = ข้อความยังอยู่ในห้อง แต่กลายเป็นแถบเทา "ยกเลิกข้อความแล้ว" อีกฝ่ายรู้ว่ามีอะไรถูกยกเลิก
**ลบข้อความ** = หายไปเลย ไม่เหลือร่องรอย

ฝั่งคุณยกเลิกได้ ระบบจะคำนวณว่าอีกฝ่าย **อ่านทันหรือไม่ทัน** โดยดูจากเวลา — ยกเลิกเร็วโอกาสรอด ปล่อยไว้นานเขาอ่านไปแล้ว ผลจะแสดงใต้ฟองว่า "ยกเลิกทัน" หรือ "อ่านทันไปก่อน" และส่งเข้าบันทึกกิจกรรมให้บอทรู้ตามจริง

แตะแถบเทาเพื่อเปิดเมนู: **ส่องเนื้อหา** · **ส่งกลับ** · **แก้ไขแล้วส่งใหม่** · **ลบทิ้งถาวร**

ฝั่งตัวละครยกเลิกได้เช่นกัน คุณส่องได้ว่าเขาเกือบพูดอะไร (ปิดได้ในตั้งค่า)

### แชทกลุ่ม

- สร้างกลุ่มเอง เลือกสมาชิก ≥2 คน ตั้งชื่อกลุ่ม
- สวิตช์ "สมาชิกรู้จักกัน" ให้คุยโต้กันได้ หรือปิดให้ต่างคนต่างคุย
- โหมดตอบ: หลายคนต่อการกดเจน หรือทีละคน
- ตั้งคูลดาวน์ระหว่างเจน กันรัว และใส่โน้ต/กติกากลุ่มให้บอทรับรู้ได้
- แสดงชื่อและรูปคนส่งแยกชัดเจน รองรับโหวตโพลในกลุ่ม
- **ตัวละครสร้างกลุ่มใหม่และดึงคุณเข้ากลุ่มได้เอง** จากเนื้อเรื่อง (ปิดได้ในตั้งค่า)

### หลายรูท (ซิงค์กับแชทของ SillyTavern)

- ตัวละครหลักหนึ่งคนมีหลายรูทได้ โดยผูกกับ **ไฟล์แชทของ SillyTavern** โดยตรง
- สลับแชทใน SillyTavern → มือถือสลับประวัติตามอัตโนมัติ
- เมนูสามจุดในหน้าแชท → "สลับรูท" เพื่อสั่งสลับจากในมือถือ (รองรับตามความสามารถของ ST เวอร์ชันนั้น)
- แต่ละรูทแยก ประวัติข้อความ · ดาว · unread · ร่าง · ประวัติการโทร ออกจากกัน ไม่ปนข้ามรูท
- กระเป๋าเงินแยกตามรูทได้ (เปิดในตั้งค่า)
- ธีมและ persona ยังใช้ร่วมทุกรูท เพราะตัวละครเป็นคนเดิม

### ระบบโทร

- โทรออกหาตัวละคร และตัวละครโทรกลับได้
- พิมพ์คุยในสาย คำพูดทยอยขึ้นทีละประโยค ตัวละครวางสายเองได้เมื่อร่ำลา
- **ปุ่มย่อสาย** — กดแล้วสายยังต่อ นาฬิกาเดินต่อ ออกไปเล่นแอปอื่นได้ Dynamic Island ด้านบนโชว์ชื่อกับเวลา แตะกลับเข้าสายได้
- **ปุ่มประวัติ** — กดเปิดเพื่อเลื่อนอ่านย้อนทั้งฝั่งคุณและฝั่งตัวละคร กดอีกทีกลับโหมดโฟกัส (ตัวใหญ่ ค่อยจางหาย)
- นับเวลาสายจากเวลาจริง กันไม่ให้ส่งข้อความซ้อนตอนอีกฝ่ายกำลังพูด
- ประวัติการโทรแยกตามคนและตามรูท ดูบทสนทนาย้อนหลังและลบได้

### คลิปเสียง

- คุณส่งได้จากเมนูแนบ ตัวละครส่งได้จากเนื้อเรื่อง
- ฟองเสียงมี **ข้อความเต็มอยู่ใต้เส้นคลื่นเสียง** อ่านได้ทันทีไม่ต้องกดอะไร
- กดปุ่มเล่นเพื่อดูคำขึ้นทีละคำเต็มจอ พร้อมข้อความเต็มค้างด้านล่าง **แตะกลางจอเพื่อหยุดค้าง** อ่านไม่ทันก็หยุดได้

### ฟีดโซเชียล (5 แท็บ)

- **หน้าแรก** — สตอรี่ + โพสต์ กดใจ คอมเมนต์ ตอบคอมเมนต์แบบชั้น รีโพสต์ แชร์เข้าแชท บันทึกโพสต์
- **สำรวจ** — แท็กมาแรง 5 อันดับยอดนิยม และโพสต์แบบกริด
- **ข่าว** — ข่าวในโลกเรื่อง อ่านแบบหน้าข่าวจริง
- **กิจกรรม** — การแจ้งเตือน คำขอติดตาม และคนที่แท็กคุณ
- **โปรไฟล์** — โพสต์ของเรา ที่บันทึกไว้ เก็บถาวร Highlights การ์ดชื่อเสียง
- กดเจนแล้ว **เลือกได้ว่าให้ตัวละครตัวไหนโพสต์**
- ในโพสต์ กดเจนแล้ว **เลือกคนที่จะคอมเมนต์ หรือสุ่มพร้อมกำหนดจำนวน**
- ตั้งการมองเห็นต่อโพสต์ได้ (ทุกคน / ผู้ติดตาม / เพื่อนสนิท / เลือกรายคน / ไม่ให้ใครเห็น)

### สตอรี่

- ลงรูปหรือข้อความ อยู่ 24 ชม. เลือกให้ทุกคนหรือเฉพาะเพื่อนสนิทเห็น
- กดหัวใจ ดูคนที่มาดู ตอบสตอรี่กันสองทาง เก็บเข้า Highlight ได้

### กระเป๋าเงิน

- โอน · ขอ · เติม · หัก เงินได้ การโอนขึ้นเป็นการ์ดในแชท
- **ปุ่มขอเงินพิมพ์ได้เอง** ทั้งจำนวนและข้อความที่จะส่งไป
- กราฟรายรับรายจ่าย 7 วัน ตั้งลิมิตต่อวันและสกุลเงินได้
- ตัวละครแต่ละคนมีกระเป๋าของตัวเอง โอนหรือขอจากกันได้
- **ตัวละครกำหนดยอดเงินตัวเองได้จากเนื้อเรื่อง** — เงินเดือนออก ถูกหวย ถังแตก (ปิดได้ในตั้งค่า)

### ชื่อเล่นที่ตัวละครตั้งให้คุณ

ตัวละครบันทึกชื่อคุณในมือถือเขาเองได้ตามความสัมพันธ์ในเรื่อง จะมีแจ้งเตือนขึ้นในแชทครั้งเดียว ปิดได้ในตั้งค่า (ปิดแล้วเขายังตั้งได้ แต่คุณต้องไปดูเองที่ตั้งค่าแชท)

### ประจำเดือน

- ปฏิทินแตะเลือกวัน แตะซ้ำเพื่อบันทึกอาการ อารมณ์ ปริมาณ โน้ต
- คำนวณรอบเฉลี่ยและคาดการณ์รอบถัดไป + ช่วงไข่ตก
- เปิด/ปิดให้บอทรับรู้ได้ ตั้งระดับความใส่ใจ และเลือกได้ว่าให้ใครรู้บ้าง
- **สถานะรอบถูกฉีดเข้า prompt สดทุกครั้งที่บอทตอบ ไม่เขียนลงไฟล์ ค่าจึงถูกต้องเสมอ** ดูข้อความที่บอทเห็นจริงได้ในแท็บความเป็นส่วนตัว

### สติกเกอร์

- **เพิ่มรูปจากเครื่องได้โดยตรง** เลือกหลายรูปพร้อมกัน ระบบย่อขนาดให้อัตโนมัติ แล้วให้ตั้งชื่อป้ายทีละรูปพร้อมโชว์รูปให้ดู
- เพิ่มด้วยลิงก์รูปก็ได้
- **นำเข้า/ส่งออกชุดเป็นไฟล์ JSON** ชื่อชุดซ้ำจะไม่เขียนทับ แต่ต่อเลขให้อัตโนมัติ
- แก้ชื่อป้ายรายรูปได้ รูปที่ยังไม่มีป้ายจะขึ้นเตือนสีส้ม เพราะ **ตัวละครเรียกสติกเกอร์จากชื่อป้าย ไม่ใช่จากรูป**
- เปิดสวิตช์ "รายชื่อป้ายสติกเกอร์" ในตั้งค่าเพื่อให้ตัวละครเห็นว่ามีสติกเกอร์อะไรใช้ได้

### สร้าง NPC เอง

- หน้าเพิ่มคนคุย → "สร้าง NPC เอง"
- ตั้งชื่อ บุคลิก และ **เลือกตัวละครหลักเป็นต้นแบบอ้างอิงบุคลิก** (ข้อมูล NPC มักอยู่ในตัวละครหลัก)
- ผูก **Lorebook** ได้ ทั้งเล่มหรือเลือกบางหัวข้อ
- ใช้ตัวอักษรตัวแรกเป็นรูป หรืออัปโหลดรูปปกเองก็ได้
- แก้ไข/ลบได้ ไม่กระทบตัวละครใน SillyTavern

### ระบบดราม่าและชื่อเสียง (ปิดเป็นค่าเริ่มต้น)

- ผู้ติดตามผี — คนแปลกหน้าที่ไม่ใช่คอนแทกต์ มาไลก์ คอมเมนต์ แอบดูสตอรี่ (ชื่อสุ่มในเครื่อง ไม่กินโทเคน)
- ยอดผู้ติดตามขึ้นลงตามที่โมเดลตัดสินคุณภาพโพสต์ — โพสต์ดีขึ้น โพสต์แย่ลง โพสต์ถี่เกินแต่เนื้อหากลาง ๆ ก็ลดได้
- ตั้งระดับความเดือดได้ ใจเย็น / ปกติ / เดือดง่าย
- ล็อคบัญชีแล้วคนแปลกหน้าหายทั้งหมด เหลือแต่คอนแทกต์จริง
- **ปิดทั้งระบบได้** ในตั้งค่า มีเลขโทเคนกำกับให้เห็น

## การเชื่อมกับบทหลัก

หัวใจของส่วนขยายนี้ มือถือกับการโรลเป็นเรื่องเดียวกัน ทำงานสองทาง

### ทางที่หนึ่ง — บอทรู้ว่าคุณทำอะไรในมือถือ

ทุกอย่างที่คุณทำ (ส่งข้อความ กดใจ โพสต์ โอนเงิน ยกเลิกข้อความ ตั้งสเตตัส) ถูกเก็บเป็นคิว

ครั้งถัดไปที่คุณเจนโรลปกติ ระบบส่งคิวนี้เข้าไปเป็น **system message แยกก้อน** ที่เขียนชัดว่าเป็นเหตุการณ์ในเรื่องที่เพิ่งเกิด ไม่ใช่เอกสารเทคนิค บอทจึงเอาไปพูดในบทได้ **ไม่แก้ไขข้อความที่คุณพิมพ์** และล้างคิวเฉพาะเมื่อคำตอบมาถึงจริง

ดูคิว ลบทีละรายการ หรือดูตัวอย่างที่จะส่งได้ในตั้งค่า

### ทางที่สอง — บทหลักสั่งมือถือได้

บอทแนบชุดข้อมูลเล็ก ๆ ท้ายคำตอบปกติ ระบบอ่านแล้วลบออกจากแชท **ไม่ยิง API รอบสอง** สิ่งที่ตัวละครทำได้

ข้อความ · คลิปเสียง · สติกเกอร์ · ตำแหน่ง · ของขวัญ · โพล · ยกเลิกข้อความ · ตอบสตอรี่ · ตั้งชื่อเล่นให้คุณ · เพิ่มตัวเองเข้าคอนแทกต์ · แชทกลุ่ม · สร้างกลุ่มดึงคุณเข้า · โทรเข้า · สายที่ไม่ได้รับ · บันทึกสายที่คุยไปแล้ว · โพสต์ · คอมเมนต์ · ไลก์ · บันทึกโพสต์ · รีโพสต์ · โหวตโพล · ลงสตอรี่ · ถูกใจสตอรี่ · โอนเงิน · ขอเงิน · กำหนดยอดเงินตัวเอง · ขอติดตาม · เลิกติดตาม · ลงสเตตัส · ข่าวในโลก

สิ่งที่ตัวละคร **ทำไม่ได้** โดยตั้งใจ — ลบแชทของคุณ ลบโพสต์ของคุณ เปลี่ยนธีม เปลี่ยนวอลเปเปอร์ แก้ยอดเงินคุณโดยตรง ปิดสวิตช์ในตั้งค่า และ **ส่งรูป** (โมเดลข้อความสร้างไฟล์รูปไม่ได้ ทำได้แค่แต่งลิงก์ปลอมซึ่งจะเห็นเป็นกล่องรูปเสีย)

## ตัวนับโทเคน — เปิดปิดรายอัน

ทุกอย่างที่ส่งให้บอทเปิดปิดได้ทีละอัน พร้อมเลขโทเคนกำกับ **วัดด้วยตัวนับของ SillyTavern เอง** ไม่ใช่การประมาณ ถ้า ST เวอร์ชันคุณไม่มีตัวนับ จะขึ้นว่า "ตัวนับของ SillyTavern ใช้ไม่ได้" ตรง ๆ ไม่เดาตัวเลขมาให้

**ประเภทเหตุการณ์** — ข้อความ/แชท · กลุ่ม+โทร · ฟีด/โพสต์/คอมเมนต์ · สตอรี่ · กระเป๋าเงิน · ติดตาม/สเตตัส · ข่าว

**ข้อมูลอ้างอิง** — รายชื่อคอนแทกต์ · รายชื่อป้ายสติกเกอร์ · โพสต์/สตอรี่ล่าสุด · สถานะ UI มือถือ · บันทึกกิจกรรมของคุณ

**ปุ่มลัดสามปุ่ม** — ปิดทั้งหมด / เท่าที่จำเป็น / เปิดทั้งหมด

### รายชื่อคอนแทกต์ — สำคัญถ้าคุณมีบอทเยอะ

เลือกได้สามระดับ พร้อมเลขโทเคนของแต่ละแบบ

**ไม่ส่งเลย** ประหยัดสุด แต่บอทมักสะกดชื่อเพี้ยน
**เฉพาะที่เกี่ยวข้อง** (ค่าเริ่มต้น) ส่งเฉพาะตัวละครที่เปิดอยู่ + NPC ของเขา + คนที่คุยใน 7 วัน + คนปักหมุด ตั้งจำนวนได้
**ทั้งหมด** คนที่มีบอทเป็นร้อยตัวจะเปลืองมาก

## หน้าผลซิงค์ — ตรวจว่าอะไรเข้าอะไรไม่เข้า

ตั้งค่า → ผลซิงค์ล่าสุด

เห็นทีละรายการว่าอะไรเข้ามือถือสำเร็จ (จุดเขียว) และอะไรตกพร้อมเหตุผลภาษาไทย (จุดแดง)

**"ไม่พบชุดข้อมูล"** = บอทลืมแนบมา ลองรีเจนคำตอบนั้น
**"ผิดรูป"** = บอทเขียน JSON เพี้ยน ระบบพยายามกู้ซากให้แล้ว
**"โมดูลปิดอยู่"** = คุณปิดโมดูลนั้นเอง ไม่ใช่บั๊ก
**"ไม่รู้จักประเภทนี้"** = บอทส่งชนิดที่ระบบยังไม่รองรับ แจ้งมาได้

พร้อมตัวเลขสรุปว่าผ่านมาแล้วกี่เทิร์น เข้าสำเร็จกี่ครั้ง พลาดกี่ครั้ง

## แก้ปัญหาเบื้องต้น

**ของไม่เข้ามือถือทั้งที่บอทเขียนในบทว่าส่งมา**
ไปหน้าผลซิงค์ดูก่อนว่าขึ้นอะไร ถ้าขึ้น "ไม่พบชุดข้อมูล" บอทลืมแนบ ลองรีเจน ถ้าขึ้น "โมดูลปิดอยู่" ให้เปิดโมดูลนั้นในตั้งค่า

**บอทไม่รู้ว่าคุณทำอะไรในมือถือ**
เปิดสวิตช์ "บันทึกกิจกรรมของคุณ" ในหมวดข้อมูลอ้างอิง และเปิด "เก็บสิ่งที่คุณทำในมือถือ"

**ตัวละครหลักโผล่ในหมวด NPC**
ตั้งค่า → ขอบเขตคอนแทกต์ → "รวมตัวละครหลักที่ถูกสร้างซ้ำ" ระบบจะยุบรวมและย้ายข้อความให้

**กดเจนแล้วไม่ตอบ**
เรียก `PP_DIAG()` ดูว่าเจอ `generateQuietPrompt` ไหม

**รูปไม่ขึ้น / กลายเป็นกล่องดำ**
พื้นที่เก็บข้อมูลเบราว์เซอร์อาจเต็ม ลองใช้รูปเล็กลง

**สติกเกอร์เพิ่มไม่ได้**
ปุ่ม "นำเข้าจากไฟล์รายการ (.json)" รับได้แค่ไฟล์รายการที่ส่งออกจากแอปนี้ ถ้าจะเพิ่มรูปให้ใช้ปุ่ม "เพิ่มรูปสติกเกอร์จากเครื่อง"

**ตัวเลขโทเคนขึ้นว่า "ยังไม่วัด"**
กดปุ่ม "วัดเลย" ในการ์ดโทเคน ถ้ายังไม่ได้แปลว่า ST เวอร์ชันนี้ไม่มีตัวนับ

**สลับรูทจากในมือถือไม่ได้**
ST บางเวอร์ชันไม่รองรับ ให้สลับแชทจาก SillyTavern ตามปกติ ฝั่งมือถือจะตามให้เอง

## ล้างแคช

หลังอัปเดตทุกครั้ง แนะนำให้ล้างแคชเบราว์เซอร์

1. เมนู `⋮` มุมขวาบนของเบราว์เซอร์ (ถ้าทำเป็นแอปให้กลับเข้า Chrome)
2. การตั้งค่า → ความเป็นส่วนตัวและความปลอดภัย
3. ลบข้อมูลการท่องเว็บ → ช่วงเวลา "ทั้งหมด"
4. เลือกเฉพาะ "รูปภาพและไฟล์ที่แคชไว้"
5. เลือกเฉพาะเว็บ SillyTavern แล้วลบ

## ข้อจำกัดที่ควรรู้

- ฝั่งเบราว์เซอร์ล้วน ไม่อ่าน/เขียนไฟล์บนดิสก์ ไม่เก็บ API key
- ฟีเจอร์ที่ต้องเรียกโมเดล (ตอบแชท โพสต์ คอมเมนต์ คุยสาย อ่านภาพ) หักโควตา API
- การให้บทหลักเด้งเข้ามือถือ ขึ้นกับว่าโมเดลทำตามรูปแบบข้อมูลแค่ไหน — โมเดลเล็กมักพลาด ดูผลได้ที่หน้าผลซิงค์
- **ตัวละครส่งรูปไม่ได้** โมเดลข้อความสร้างไฟล์รูปไม่ได้ ส่งได้แค่สติกเกอร์ที่คุณเพิ่มไว้เอง
- การสลับ/ลิสต์แชทจากในมือถือขึ้นกับ API ของ SillyTavern แต่ละเวอร์ชัน
- ข้อมูลเก็บใน `extensionSettings` และ `localforage` ของเบราว์เซอร์ ล้างข้อมูลเว็บทั้งหมดแล้วข้อมูลมือถือจะหาย
