# Pocket Phone

มือถือจำลองเต็มจอสำหรับ SillyTavern — แชท โทร ฟีดโซเชียล ปั้นโปรไฟล์ กระเป๋าเงิน และอื่น ๆ กับตัวละครในเครื่องของคุณ ทำงานฝั่งเบราว์เซอร์ล้วน ไม่ต้องติดตั้งเซิร์ฟเวอร์เสริม

**เวอร์ชัน 2.1.0**

> **หมายเหตุเรื่องโควตา** ทุกครั้งที่กดให้ตัวละครตอบ โพสต์ คอมเมนต์ หรือคุยสาย จะเรียกโมเดลเหมือนการโรลปกติ **จึงหักโควตา API ตามการใช้งานจริง**
>
> ส่วนการเชื่อมกับบทหลักทำงานแบบ **หนึ่งคำขอเท่านั้น** ไม่ยิง API รอบสองลับหลัง และมีตัวนับโทเคนในตัวให้ดูว่าเปิดอะไรกินเท่าไหร่

## ติดตั้ง

1. เปิด SillyTavern → **Extensions** → **Install Extension**
2. วางลิงก์ repo นี้แล้วติดตั้ง
3. รีเฟรชหน้า
4. เปิดใช้งานได้จาก **ปุ่มลอย** (ลากย้ายได้) หรือเมนู **wand (Extensions)**

> อัปเดตแล้วแนะนำให้ล้างแคชเบราว์เซอร์ (ดูหัวข้อ [ล้างแคช](#ล้างแคช))

---

## เริ่มใช้งานครั้งแรก

**หนึ่ง** เปิดมือถือ → ตั้งค่า → **สะพานเชื่อมกับบทหลัก** → กดปุ่มมุมขวาบนเพื่อวัดโทเคน ตัวเลขนี้มาจากตัวนับของ SillyTavern เอง ไม่ใช่การประมาณ

**สอง** ในหน้าเดียวกัน กดปุ่ม **เท่าที่จำเป็น** เป็นค่าเริ่มต้นที่สมดุลระหว่างความสมจริงกับโทเคน

**สาม** หน้าข้อความ → ปุ่มดินสอมุมขวาบน → เพิ่มตัวละครจาก SillyTavern เข้ามาเป็นรายชื่อคนคุย

---

## แอปข้อความ

- เพิ่มตัวละครจาก SillyTavern เข้ามาเป็นรายชื่อคนคุย
- แชทเป็นข้อความจริง กด Enter ส่ง แล้วกดปุ่มดาวให้ตัวละครตอบ พิมพ์รัวหลายข้อความก่อนค่อยให้ตอบก็ได้
- ฟองแชทจับกลุ่ม มีเส้นคั่นเวลา สถานะส่งแล้วอ่านแล้ว และเวลากำกับ
- แท็บรายชื่อ ยังไม่อ่าน ปักหมุด ตัวละคร NPC เรียงตามที่คุยล่าสุด
- ปัดแถวแชทเพื่อปักหมุด ปิดเสียง เก็บเข้าคลัง หรือลบ
- ปัดฟองไปขวาเพื่อตอบข้อความนั้น แตะฟองเพื่อตอบ ติดดาว แก้ไข ยกเลิก แชร์ เลือกหลายข้อความ หรือลบ
- ค้นหาในห้อง และค้นหาข้ามทุกแชทได้
- แนบได้หลายแบบ รูป ตำแหน่ง การ์ดคอนแทกต์ ข้อความเสียง โพล โอนเงิน ของขวัญ ตั้งเวลาส่ง
- ปรับแต่งแยกต่อคน พื้นหลังแชท สีฟอง สีตัวอักษร ฟองกระจก ทรงฟอง รูปเป็นพื้นฟอง เสียงเรียกเข้าเฉพาะห้อง
- Persona ตั้งชื่อและบุคลิกของตัวละครเฉพาะในมือถือ และเลือก persona ของผู้ใช้ที่ตัวละครคนนั้นรับรู้ ไม่กระทบข้อมูลจริงใน SillyTavern

## ยกเลิกข้อความ (ต่างจากลบ)

**ยกเลิกข้อความ** ข้อความยังอยู่ในห้อง แต่กลายเป็นแถบเทา อีกฝ่ายรู้ว่ามีอะไรถูกยกเลิก
**ลบข้อความ** หายไปเลย ไม่เหลือร่องรอย

ฝั่งคุณยกเลิกได้ ระบบคำนวณว่าอีกฝ่าย **อ่านทันหรือไม่ทัน** ตามเวลาจริง ยกเลิกเร็วโอกาสรอด ปล่อยไว้นานเขาอ่านไปแล้ว ผลแสดงใต้ฟองและส่งเข้าบันทึกกิจกรรมให้ตัวละครรู้ตามจริง

แตะแถบเทาเพื่อเปิดเมนู **ส่องเนื้อหา · ส่งกลับ · แก้ไขแล้วส่งใหม่ · ลบทิ้งถาวร**

ฝั่งตัวละครยกเลิกได้เช่นกัน คุณส่องได้ว่าเขาเกือบพูดอะไร ปิดได้ในตั้งค่า

## แชทกลุ่ม

- สร้างกลุ่มเอง เลือกสมาชิกตั้งแต่สองคน ตั้งชื่อกลุ่ม
- สวิตช์สมาชิกรู้จักกันให้คุยโต้กันได้ หรือปิดให้ต่างคนต่างคุย
- โหมดตอบหลายคนต่อการกดเจน หรือทีละคน
- ตั้งคูลดาวน์ระหว่างเจน และใส่โน้ตกติกากลุ่มให้ตัวละครรับรู้ได้
- **ตัวละครสร้างกลุ่มใหม่และดึงคุณเข้ากลุ่มได้เอง** จากเนื้อเรื่อง ปิดได้ในตั้งค่า

## หลายรูท (ซิงค์กับแชทของ SillyTavern)

- ตัวละครหลักหนึ่งคนมีหลายรูทได้ ผูกกับไฟล์แชทของ SillyTavern โดยตรง
- สลับแชทใน SillyTavern มือถือสลับประวัติตามอัตโนมัติ
- เมนูสามจุดในหน้าแชท สลับรูท เพื่อสั่งสลับจากในมือถือ ตามที่ ST เวอร์ชันนั้นรองรับ
- แต่ละรูทแยกประวัติข้อความ ดาว ยังไม่อ่าน ร่าง ประวัติการโทร ไม่ปนข้ามรูท
- กระเป๋าเงินแยกตามรูทได้ เปิดในตั้งค่า

## ระบบโทร

- โทรออกหาตัวละคร และตัวละครโทรกลับได้
- **สายเจนรอบเดียวได้ครบสามท่อน** ตัวละครพิมพ์บอกก่อนโทร เว้นให้อ่าน สายจึงเข้า กดรับแล้วบทเปิดเล่นทันทีไม่ต้องรอโหลด ปฏิเสธหรือไม่รับสายเขาจะส่งข้อความมาเองโดยไม่ต้องกดเจน
- **ปุ่มย่อสาย** กดแล้วสายยังต่อ นาฬิกาเดินต่อ ออกไปเล่นแอปอื่นได้ Dynamic Island โชว์ชื่อกับเวลา แตะกลับเข้าสายได้
- **ปุ่มประวัติ** กดเปิดเพื่อเลื่อนอ่านย้อนทั้งฝั่งคุณและฝั่งตัวละคร กดอีกทีกลับโหมดโฟกัส
- ปรับเวลาเว้นให้อ่านก่อนสายเข้าได้สี่ระดับ
- ประวัติการโทรแยกตามคนและตามรูท ดูบทสนทนาย้อนหลังและลบได้

## คลิปเสียง

- คุณส่งได้จากเมนูแนบ ตัวละครส่งได้จากเนื้อเรื่อง
- ฟองเสียงมี **ข้อความเต็มอยู่ใต้เส้นคลื่นเสียง** อ่านได้ทันทีไม่ต้องกดอะไร
- กดปุ่มเล่นเพื่อดูคำขึ้นทีละคำเต็มจอ **แตะกลางจอเพื่อหยุดค้าง** อ่านไม่ทันก็หยุดได้

## ฟีดโซเชียล (5 แท็บ)

- **หน้าแรก** สตอรี่และโพสต์ กดใจ คอมเมนต์ ตอบคอมเมนต์แบบชั้น รีโพสต์ แชร์เข้าแชท บันทึกโพสต์
- **สำรวจ** แท็กมาแรง ห้าอันดับยอดนิยม ค้นหาคนและโพสต์
- **ข่าว** ข่าวในโลกเรื่อง อ่านแบบหน้าข่าวจริง
- **กิจกรรม** การแจ้งเตือน คำขอติดตาม คนที่แท็กคุณ
- **โปรไฟล์** โพสต์ของเรา ที่บันทึกไว้ เก็บถาวร Highlights การ์ดชื่อเสียง

**กดปุ่มดาวแล้วเลือกได้** สุ่มหนึ่ง สอง สาม หรือห้าคน กดครั้งเดียว หรือเลือกรายคนหลายคน หรือค้นหาชื่อ

**โพสต์หลายคนยิงคำขอเดียว** ประหยัดกว่ายิงทีละคน และสั่งให้แต่ละคนเขียนคนละเสียงจริง ไม่กลืนเป็นเสียงเดียว

**คอมเมนต์โต้ตอบกันเอง** ครึ่งหนึ่งตอบคนอื่น สร้างเป็นเธรดเล็ก ๆ แบบคอมเมนต์จริง พร้อม **ตัวบ่งชี้กำลังพิมพ์** ที่ทยอยขึ้นทีละคน เห็นรูปโปรไฟล์คนที่กำลังพิมพ์ก่อนข้อความจะปรากฏ

ตั้งการมองเห็นต่อโพสต์ได้ ทุกคน ผู้ติดตาม เพื่อนสนิท เลือกรายคน หรือไม่ให้ใครเห็น

## หน้าโปรไฟล์แบบ IG

- หัวโปรไฟล์มีรูปปก รูปโปรไฟล์ ชื่อแอค bio ลิงก์ และตัวเลขสามช่อง
- แถบไฮไลท์กดเข้าไปดูได้จริง
- **แท็บรูป** กริดสามคอลัมน์ กดค้างเห็นยอดใจกับคอมเมนต์ กดเข้าไปดูโพสต์นั้น
- **แท็บข้อความ** ไทม์ไลน์ไล่ประวัติทั้งหมด เลื่อนยาว เห็นยอดใจ คอมเมนต์ รีโพสต์ และคอมเมนต์สองอันแรก
- โพสต์หนึ่งอันใส่หลายรูปได้ ปัดซ้ายขวา มีจุดบอกตำแหน่ง
- สามทางเข้า แตะรูปหรือชื่อในหัวโพสต์ เข้าจากเมนูในแชท หรือค้นหาในแท็บสำรวจ
- ตัวเลขใหญ่ย่อแบบสากล 3k 4.7k 58k 6.8m

## ปั้นโปรไฟล์และฝังลงการ์ด

ปั้นได้ครบทั้งชุดต่อตัวละคร ทั้งของตัวเองและ NPC ที่ผูกไว้

- ชื่อ ชื่อแอค รูปโปรไฟล์ รูปปก bio ลิงก์ ยอดผู้ติดตาม ยอดที่กำลังติดตาม
- **ไฮไลท์** ตั้งปกได้ ลงสตอรี่เข้าไฮไลท์ได้ทั้งรูป วิดีโอ และข้อความ **เก็บถาวรไม่หายหลัง 24 ชม.** ป้ายเวลาสามระดับ ไม่เกินเดือนนับวัน เกินเดือนแสดงวันกับเดือน เกินปีใส่ปีด้วย
- **คลังโพสต์ย้อนหลัง** แยกโพสต์รูปกับโพสต์ข้อความ ตั้งวันเวลาจริงได้ ใส่หลายรูปได้ ใส่ไฟล์เสียงได้ กำหนดยอดใจและยอดรีโพสต์ได้
- **คอมเมนต์เขียนเองได้** เลือกคนพูดจาก NPC ที่ผูกไว้ หรือแอคผีในคลังที่ตั้งชื่อกับรูปครั้งเดียวแล้วใช้ซ้ำได้ทุกโพสต์
- **NPC ที่ผูกไว้** ปั้นโปรไฟล์ของเขาได้ครบเหมือนตัวหลัก และติดไปกับการ์ดพร้อมกัน

**ฝังลงตัวการ์ดโดยตรง** ส่งการ์ดให้เพื่อน เขาลากเข้า SillyTavern แล้วเพิ่มเข้ามือถือ โปรไฟล์โผล่มาครบพร้อมย้อนหลังทันที **ไม่กินโทเคนแม้แต่ตัวเดียว** เพราะข้อมูลอยู่ในส่วนขยาย ไม่เคยเข้า prompt

มีปุ่มดาวน์โหลดสำรองก่อนเขียน และปุ่มอัปเดตเพื่ออ่านค่าจากการ์ดใหม่ แก้ข้อมูลเพิ่มแล้วต้องกดฝังใหม่ทุกครั้ง

**ตั้งรหัสล็อกได้** คนที่ได้การ์ดไปเห็นโปรไฟล์ครบ เลื่อนดูได้ทุกอย่าง แต่ปุ่มแก้ไขหายไป มีหน้าใส่รหัสแบบจุด ๆ และปุ่มล้างทิ้งเพื่อปั้นใหม่เองสำหรับคนที่ไม่รู้รหัส

> **ข้อจำกัดของรหัสล็อกที่ต้องรู้** มันกันคนแก้พลาดได้ แต่กันคนตั้งใจแก้ไม่ได้จริง เพราะคนที่รู้วิธีเปิดเครื่องมือนักพัฒนาในเบราว์เซอร์อ่านข้อมูลได้หมด ถือว่าเป็นป้ายห้ามจับ ไม่ใช่กุญแจ

**รูปทุกช่องรับแต่ลิงก์** เพราะรูปที่ดึงจากเครื่องจะไม่ติดไปกับการ์ด มีปุ่มทดสอบลิงก์ให้กดก่อนบันทึก ผ่านขึ้นเขียว ไม่ผ่านบอกเหตุผล

## ฝากรูปให้ตัวละครโพสต์

ส่งรูปเข้าแชท แตะฟองรูป เลือก **ฝากให้เอาไปโพสต์** เลือกลงฟีดหรือสตอรี่ พิมพ์กำกับได้ว่าอยากให้โพสต์ทำนองไหน

เจนโรลครั้งถัดไปตัวละครจะเห็นคำบรรยายรูปที่คุณเขียน และตัดสินใจเอง **เขาปฏิเสธได้** ถ้าไม่ใช่นิสัยเขา ถ้าลง โพสต์จะมีรูปจริงที่คุณส่งไป

เปลี่ยนใจได้ แตะแถบสีฟ้าในหน้าฟีดเพื่อถอนคำขอทีละใบหรือทั้งหมด

## สตอรี่

- ลงรูปหรือข้อความ อยู่ 24 ชม. เลือกให้ทุกคนหรือเฉพาะเพื่อนสนิทเห็น
- กดหัวใจ ดูคนที่มาดู ตอบสตอรี่กันสองทาง เก็บเข้า Highlight ได้
- รองรับลิงก์รูปและวิดีโอ ใส่ไฟล์เสียงต่อสตอรี่ได้ เลื่อนไปอันถัดไปเสียงเก่าหยุดเอง

## เสียงในแอป

ใส่เพลงประกอบโพสต์และสตอรี่ได้ **ปุ่มลำโพงกลมมุมขวาล่างของรูป**

เบราว์เซอร์ห้ามเล่นเสียงเองจนกว่าคุณจะแตะจอ แตะปุ่มลำโพงครั้งแรกครั้งเดียว จากนั้นเลื่อนไปโพสต์อื่นเพลงจะสลับให้เอง ตัวเล่นเสียงมีตัวเดียวทั้งแอปจึงไม่มีทางซ้อนกัน ปิดมือถือเสียงหยุด

> ลิงก์เสียงกับวิดีโอต้องเป็นไฟล์ตรง ๆ โฮสต์หลายเจ้าบล็อกการดึงข้ามเว็บ ใช้ปุ่มทดสอบลิงก์ก่อนบันทึกทุกครั้ง

## กระเป๋าเงิน

- โอน ขอ เติม หัก การโอนขึ้นเป็นการ์ดในแชท
- **ปุ่มขอเงินพิมพ์เองได้** ทั้งจำนวนและข้อความที่จะส่งไป
- กราฟรายรับรายจ่ายเจ็ดวัน ตั้งลิมิตต่อวันและสกุลเงินได้
- ตัวละครมีกระเป๋าของตัวเอง โอนหรือขอจากกันได้
- **ตัวละครกำหนดยอดเงินตัวเองได้จากเนื้อเรื่อง** เงินเดือนออก ถูกหวย ถังแตก ปิดได้ในตั้งค่า

## ชื่อเล่นที่ตัวละครตั้งให้คุณ

ตัวละครบันทึกชื่อคุณในมือถือเขาเองได้ตามความสัมพันธ์ในเรื่อง มีแจ้งเตือนขึ้นในแชทครั้งเดียว ปิดได้ในตั้งค่า ปิดแล้วเขายังตั้งได้ แต่ต้องไปดูเองที่ตั้งค่าแชท

## ประจำเดือน

- ปฏิทินแตะเลือกวัน แตะซ้ำเพื่อบันทึกอาการ อารมณ์ ปริมาณ โน้ต
- คำนวณรอบเฉลี่ยและคาดการณ์รอบถัดไป พร้อมช่วงไข่ตก
- เปิดปิดให้ตัวละครรับรู้ได้ ตั้งระดับความใส่ใจ และเลือกได้ว่าให้ใครรู้บ้าง
- **สถานะรอบฉีดเข้า prompt สดทุกครั้งที่ตัวละครตอบ ไม่เขียนลงไฟล์ ค่าจึงถูกต้องเสมอ** ดูข้อความที่เขาเห็นจริงได้ในแท็บความเป็นส่วนตัว

## สติกเกอร์

- **เพิ่มรูปจากเครื่องได้โดยตรง** เลือกหลายรูปพร้อมกัน ระบบย่อให้อัตโนมัติ **รักษาพื้นใส** แล้วให้ตั้งชื่อป้ายทีละรูปพร้อมโชว์รูปให้ดู
- GIF เคลื่อนไหวได้ตามปกติ ไม่ถูกย่อจนเหลือเฟรมเดียว
- เพิ่มด้วยลิงก์รูปก็ได้ นำเข้าและส่งออกชุดเป็นไฟล์ JSON ได้
- แก้ชื่อป้ายรายรูปได้ รูปที่ยังไม่มีป้ายขึ้นเตือนสีส้ม เพราะ **ตัวละครเรียกสติกเกอร์จากชื่อป้าย ไม่ใช่จากรูป**
- เปิดสวิตช์รายชื่อป้ายสติกเกอร์ในตั้งค่าเพื่อให้เขาเห็นว่ามีอะไรใช้ได้

## สร้าง NPC เอง

- หน้าเพิ่มคนคุย → สร้าง NPC เอง
- ตั้งชื่อ บุคลิก และเลือกตัวละครหลักเป็นต้นแบบอ้างอิงบุคลิก
- ผูก **Lorebook** ได้ ทั้งเล่มหรือเลือกบางหัวข้อ
- อัปโหลดรูปปกเองได้ หรือใช้ตัวอักษรตัวแรก
- ปั้นโปรไฟล์ฟีดให้เขาได้ครบเหมือนตัวหลัก และติดไปกับการ์ดพร้อมกัน

## ระบบดราม่าและชื่อเสียง (ปิดเป็นค่าเริ่มต้น)

- **ผู้ติดตามผี** คนแปลกหน้าที่ไม่ใช่คอนแทกต์ มาไลก์ คอมเมนต์ แอบดูสตอรี่ ชื่อสุ่มในเครื่อง ไม่กินโทเคน
- ยอดผู้ติดตามขึ้นลงตามที่โมเดลตัดสินคุณภาพโพสต์ โพสต์ดีขึ้น โพสต์แย่ลง โพสต์ถี่เกินแต่เนื้อหากลาง ๆ ก็ลดได้
- ตั้งระดับความเดือดได้ ใจเย็น ปกติ เดือดง่าย
- ล็อกบัญชีแล้วคนแปลกหน้าหายทั้งหมด เหลือแต่คอนแทกต์จริง
- ปิดทั้งระบบได้ มีเลขโทเคนกำกับให้เห็นก่อนเปิด

## การเชื่อมกับบทหลัก

หัวใจของส่วนขยายนี้ มือถือกับการโรลเป็นเรื่องเดียวกัน ทำงานสองทาง

### ทางที่หนึ่ง — บอทรู้ว่าคุณทำอะไรในมือถือ

ทุกอย่างที่คุณทำถูกเก็บเป็นคิว ครั้งถัดไปที่คุณเจนโรลปกติ ระบบส่งคิวนี้เข้าไปเป็น **system message แยกก้อน** ที่เขียนชัดว่าเป็นเหตุการณ์ในเรื่องที่เพิ่งเกิด ตัวละครจึงเอาไปพูดในบทได้ **ไม่แก้ไขข้อความที่คุณพิมพ์** และล้างคิวเฉพาะเมื่อคำตอบมาถึงจริง

บันทึกยุบเป็นกลุ่มตามหัวเรื่อง ประหยัดโทเคนราวสามสิบเปอร์เซ็นต์และอ่านง่ายขึ้นพร้อมกัน

```
[แชท]
- ส่งข้อความให้ รวิศ:
  ├ <q>"อันแรก"</q>
  ├ <q>"อันสอง"</q>
  └ <q>"อันสาม"</q>
```

### ทางที่สอง — ตัวละครรู้ว่าตัวเองทำอะไร

**กระจกฝั่งบอท** เก็บทุกอย่างที่ตัวละครทำในมือถือ ข้อความที่ตอบ สายที่โทรมา โพสต์ คอมเมนต์ สตอรี่ เงินที่โอน ชื่อเล่นที่ตั้งให้คุณ ข้อความที่ยกเลิก

ส่งรวมก้อนเดียวกับฝั่งคุณ เรียงตามเวลา ตัวละครจึงจำได้ว่าตัวเองรับปากอะไรไว้ **ไม่เขียนขัดกับตัวเองในโรลหลักอีก**

บทสนทนาในสายเลือกได้สามระดับ ไม่ส่ง สรุปสามประโยคท้าย หรือส่งทั้งบท

### ทางที่สาม — บทหลักสั่งมือถือได้

ตัวละครแนบชุดข้อมูลเล็ก ๆ ท้ายคำตอบปกติ ระบบอ่านแล้วลบออกจากแชท **ไม่ยิง API รอบสอง**

สิ่งที่ตัวละครทำได้ ข้อความ คลิปเสียง สติกเกอร์ ตำแหน่ง ของขวัญ โพล ยกเลิกข้อความ ตอบสตอรี่ ตั้งชื่อเล่น เพิ่มตัวเองเข้าคอนแทกต์ แชทกลุ่ม สร้างกลุ่มดึงคุณเข้า โทรเข้า สายที่ไม่ได้รับ บันทึกสายที่คุยไปแล้ว โพสต์ คอมเมนต์ ไลก์ บันทึกโพสต์ รีโพสต์ แชร์เข้าแชท โหวตโพล ลงสตอรี่ ถูกใจสตอรี่ โอนเงิน ขอเงิน กำหนดยอดเงินตัวเอง ขอติดตาม เลิกติดตาม ลงสเตตัส ลงข่าวในโลก

มีกฎบังคับว่า **คำพูดกับข้อมูลต้องตรงกัน** ถ้าเขาบอกว่าโพสต์แล้วต้องแนบข้อมูลมาด้วย ไม่งั้นให้บอกตรง ๆ ว่ายังไม่ได้ทำ

สิ่งที่ตัวละคร **ทำไม่ได้** โดยตั้งใจ ลบแชทของคุณ ลบโพสต์ของคุณ เปลี่ยนธีม เปลี่ยนวอลเปเปอร์ แก้ยอดเงินคุณโดยตรง ปิดสวิตช์ในตั้งค่า และ **ส่งรูป** เพราะโมเดลข้อความสร้างไฟล์รูปไม่ได้ ทำได้แค่แต่งลิงก์ปลอมซึ่งจะเห็นเป็นกล่องรูปเสีย

## ตัวนับโทเคน — เปิดปิดรายอัน

ทุกอย่างที่ส่งให้ตัวละครเปิดปิดได้ทีละอัน พร้อมเลขโทเคนกำกับ **วัดด้วยตัวนับของ SillyTavern เอง** ไม่ใช่การประมาณ ถ้า ST เวอร์ชันคุณไม่มีตัวนับ จะขึ้นว่าใช้ไม่ได้ตรง ๆ ไม่เดาตัวเลขมาให้

**ประเภทเหตุการณ์** ข้อความและแชท · กลุ่มและโทร · ฟีดโพสต์คอมเมนต์ · สตอรี่ · กระเป๋าเงิน · ติดตามและสเตตัส · ข่าว

**ข้อมูลอ้างอิง** รายชื่อคอนแทกต์ · รายชื่อป้ายสติกเกอร์ · โพสต์และสตอรี่ล่าสุด · สถานะ UI มือถือ · บันทึกกิจกรรมสองฝั่ง

**ปุ่มลัดสามปุ่ม** ปิดทั้งหมด · เท่าที่จำเป็น · เปิดทั้งหมด

### รายชื่อคอนแทกต์ — สำคัญถ้าคุณมีตัวละครเยอะ

เลือกได้สามระดับ พร้อมเลขโทเคนของแต่ละแบบ

**ไม่ส่งเลย** ประหยัดสุด แต่ตัวละครมักสะกดชื่อเพี้ยน
**เฉพาะที่เกี่ยวข้อง** ค่าเริ่มต้น ส่งเฉพาะตัวที่เปิดอยู่ NPC ของเขา คนที่คุยในเจ็ดวัน และคนปักหมุด ตั้งจำนวนได้
**ทั้งหมด** คนที่มีตัวละครเป็นร้อยตัวจะเปลืองมาก

## หน้าผลซิงค์ — ตรวจว่าอะไรเข้าอะไรไม่เข้า

ตั้งค่า → สะพานเชื่อมกับบทหลัก → ผลซิงค์ล่าสุด

เห็นทีละรายการว่าอะไรเข้ามือถือสำเร็จ จุดเขียว และอะไรตกพร้อมเหตุผลภาษาไทย จุดแดง

**ไม่พบชุดข้อมูล** ตัวละครลืมแนบมา ลองรีเจนคำตอบนั้น
**ผิดรูป** เขียน JSON เพี้ยน ระบบพยายามกู้ซากให้แล้ว
**โมดูลปิดอยู่** คุณปิดโมดูลนั้นเอง ไม่ใช่บั๊ก
**ไม่รู้จักประเภทนี้** ส่งชนิดที่ระบบยังไม่รองรับ แจ้งมาได้

พร้อมตัวเลขสรุปว่าผ่านมาแล้วกี่เทิร์น เข้าสำเร็จกี่ครั้ง พลาดกี่ครั้ง

## แก้ปัญหาเบื้องต้น

**ตัวละครบอกว่าโพสต์แล้วแต่ไม่มีอะไรขึ้น**
ไปดูหน้าผลซิงค์ก่อน ถ้าขึ้นว่าไม่พบชุดข้อมูล เขาลืมแนบ ลองรีเจน ถ้าขึ้นว่าโมดูลปิดอยู่ ให้เปิดโมดูลฟีดในตั้งค่า

**ตัวละครไม่รู้ว่าคุยอะไรกันในมือถือ**
เปิดสวิตช์บันทึกกิจกรรมสองฝั่งในหมวดข้อมูลอ้างอิง และเปิดกระจกฝั่งบอทในหมวดความจำสองฝั่ง สองอันนี้คือสิ่งที่ทำให้มือถือกับการโรลเชื่อมกัน

**ตัวละครเขียนขัดกับสิ่งที่เพิ่งพูดในมือถือ**
เปิดกระจกฝั่งบอท และตรวจว่าคิวไม่ว่างเปล่าที่หมวดความจำสองฝั่ง

**ตัวละครหลักโผล่ในหมวด NPC**
ตั้งค่า → ขอบเขตคอนแทกต์ → รวมตัวละครหลักที่ถูกสร้างซ้ำ ระบบจะยุบรวมและย้ายข้อความให้

**ย้ายเครื่องแล้วโปรไฟล์ไม่มา**
ลากการ์ดเข้า SillyTavern แล้วเพิ่มตัวละครนั้นเข้าคอนแทกต์ กล่องจะเด้งเองบอกว่านำเข้ากี่รายการ ถ้าไม่เด้ง เข้าโปรไฟล์เขา เมนูสามจุด นำเข้าโปรไฟล์จากการ์ด

**สติกเกอร์เป็นสี่เหลี่ยมดำ**
รูปที่เสียไปแล้วกู้ไม่ได้ ต้องเพิ่มใหม่ รุ่นใหม่รักษาพื้นใสแล้ว ลบรูปดำทิ้งได้เลย

**เพลงในโพสต์ไม่ดัง**
แตะปุ่มลำโพงครั้งแรกก่อน เบราว์เซอร์ห้ามเล่นเองจนกว่าจะแตะจอ ถ้าไม่ดังเลยลิงก์อาจถูกโฮสต์บล็อก ใช้ปุ่มทดสอบลิงก์ดู

**กดเจนแล้วไม่ตอบ**
เรียก `PP_DIAG()` ดูว่าเจอ `generateQuietPrompt` ไหม

**รูปไม่ขึ้นหรือกลายเป็นกล่องดำ**
พื้นที่เก็บข้อมูลเบราว์เซอร์อาจเต็ม ใช้รูปเล็กลง หรือใช้ลิงก์แทน รูปจากลิงก์ไม่กินพื้นที่และส่งต่อไปเครื่องคนอื่นได้

**ตัวเลขโทเคนขึ้นว่ายังไม่วัด**
กดปุ่มมุมขวาบนในหมวดสะพานเชื่อม ถ้ายังไม่ได้แปลว่า ST เวอร์ชันนี้ไม่มีตัวนับ

**สลับรูทจากในมือถือไม่ได้**
ST บางเวอร์ชันไม่รองรับ ให้สลับแชทจาก SillyTavern ตามปกติ ฝั่งมือถือจะตามให้เอง

---

## ล้างแคช

หลังอัปเดตทุกครั้ง แนะนำให้ล้างแคชเบราว์เซอร์

1. เมนู `⋮` มุมขวาบนของเบราว์เซอร์ ถ้าทำเป็นแอปให้กลับเข้า Chrome
2. การตั้งค่า → ความเป็นส่วนตัวและความปลอดภัย
3. ลบข้อมูลการท่องเว็บ → ช่วงเวลาทั้งหมด
4. เลือกเฉพาะรูปภาพและไฟล์ที่แคชไว้
5. เลือกเฉพาะเว็บ SillyTavern แล้วลบ

---

## ข้อจำกัดที่ควรรู้

- ฝั่งเบราว์เซอร์ล้วน ไม่อ่านหรือเขียนไฟล์บนดิสก์ ไม่เก็บ API key
- ฟีเจอร์ที่ต้องเรียกโมเดล ตอบแชท โพสต์ คอมเมนต์ คุยสาย หักโควตา API
- การให้บทหลักเด้งเข้ามือถือขึ้นกับว่าโมเดลทำตามรูปแบบข้อมูลแค่ไหน โมเดลเล็กมักพลาด ดูผลได้ที่หน้าผลซิงค์
- **ตัวละครส่งรูปไม่ได้** โมเดลข้อความสร้างไฟล์รูปไม่ได้ ส่งได้แค่สติกเกอร์ที่คุณเพิ่มไว้เอง
- **รหัสล็อกโปรไฟล์กันคนตั้งใจแก้ไม่ได้** กันได้แค่การแก้พลาด
- ลิงก์เสียงและวิดีโอขึ้นกับว่าโฮสต์ยอมให้เว็บอื่นดึงไฟล์ไหม ใช้ปุ่มทดสอบลิงก์ก่อนบันทึก
- การสลับหรือลิสต์แชทจากในมือถือขึ้นกับ API ของ SillyTavern แต่ละเวอร์ชัน
- ข้อมูลเก็บใน `extensionSettings` และ `localforage` ของเบราว์เซอร์ ล้างข้อมูลเว็บทั้งหมดแล้วข้อมูลมือถือจะหาย

## ข้อเสนอแนะ

เจอบั๊ก อยากได้ฟีเจอร์ หรือมีคำถาม เปิด Issue ได้เลย

แจ้งบั๊กเรื่องของไม่เข้ามือถือ **แนบภาพหน้าผลซิงค์มาด้วย** จะหาต้นเหตุได้เร็วขึ้นมาก

ขอบคุณทุกคนที่ช่วยกันเทสต์ครับ
